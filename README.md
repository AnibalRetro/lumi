## 📦 Requisitos Previos

Antes de comenzar, asegúrate de tener instalado:

- **Node.js** (versión 16 o superior)
- **npm** o **yarn**
- Una **API key de Gemini** (obtener en [Google AI Studio](https://ai.google.dev/))

---

## 🚀 Instalación

### 1. Clonar el Repositorio

```bash
git clone https://github.com/AnibalRetro/lumi.git
cd lumi
```

### 2. Instalar Dependencias

```bash
npm install
```

---

## ⚙️ Configuración

### Configurar la API Key de Gemini

1. Abre el archivo `.env.local` en la raíz del proyecto
2. Añade tu clave de API de Gemini:

```env
GEMINI_API_KEY=tu_clave_aqui
```

> **Nota:** Nunca commits tu `.env.local` a control de versiones. Este archivo está en `.gitignore`.

## 💻 Uso

### Ejecutar en Desarrollo

```bash
npm run dev
```

La aplicación estará disponible en `http://localhost:3000` (o el puerto configurado)
